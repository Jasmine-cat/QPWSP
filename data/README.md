# Data

This repository expects EPANET-compatible WDN models in `.inp` format under this directory.

The benchmark networks used in the manuscript include Hanoi, Richmond, CY-DMA, EX, and other public WDN models. Network files are not included unless their redistribution license permits public sharing.

If a benchmark file is not included, obtain it from its original source and place it under `data/` using the filename expected by the corresponding configuration file.

This minimal public release focuses on cleaned code and reproducibility structure. Data-source details can be added here before the repository is made fully public.
